Steps to run the program

1. Go to tikwmapi.com and sign up 
2. Head over to https://tikwmapi.com/dashboard

There will be somewhere an option where new users get $30 credits

3. Go to https://tikwmapi.com/dashboard/plan

With the free credit you got enable the Trial Plan $18.00/mo

4. Go to https://tikwmapi.com/dashboard/keys and create a random key then copy it's value

Required variables to change in config.json

TIKWM_API_KEY - from Step 4

DISCORD_WEBHOOK - Discord server and in integrations create a webhook for the channel (only PC)

DISCORD_MENTION_ID - Put your discord ID where you see the YOUR_DISCORD_ID

ACCOUNTS array - for each string you put your ACCOUNTS

Since this is a python program you need to run the following commands:

5. pip install -r requirements.txt
6. python main.py



Of course, feel free to use AI to expand this project into something much bigger, this is just basics :)

Enjoy
